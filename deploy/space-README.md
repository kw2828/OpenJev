# OpenJev

English context, questions and candidate answers become candidate probabilities.
Includes a real ViZDoom arena using the same decision interface.

This Space runs **Qwen3-0.6B on CPU**, not the Mac Qwen3-4B model in the recorded GIF.
Scores are uncalibrated. This is a shared demo: Doom controls and instructions are
visible to every visitor. Use sample text only. No paid API is enabled.

Source and setup: https://github.com/kw2828/OpenJev
