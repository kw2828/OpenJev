# Retrospective decision-error decomposition

The [head-initialization study](finite-head-learning-results.md) remains a failed
continuation, 14/15 conditions. The rounded random-head candidate has lower
four-action prediction MSE in its losing H8 comparison, yet higher decision
regret. This diagnostic describes that discrepancy without fitting a new model,
changing any criterion, or admitting a further architecture experiment.

Use all 486 retained BASE cases, all three arms, all five original seeds and
H1/H2/H4/H8. Save 29,160 case records with original true/predicted four-action
cost vectors and case identities. Retain first-index argmin ties, regret,
four-action MSE, action-centered MSE, true best/second-best margin and the
predicted contrast between the chosen action and true best action. These are
descriptive development-data analyses, not untouched confirmation.

For every H4/H8 seed, compare rounded random to both matched-free random and
the descriptive rounded anchor: 20 paired groups. Partition every case by
the exact sign of its regret difference. Sum each category's contribution
using the full 486-case denominator, alongside its within-category mean and
action-disagreement count. Separately retain fixed true-margin intervals
[0,0.001), [0.001,0.01), [0.01,0.1), [0.1,infinity). Include empty intervals,
every case and every seed; do not select thresholds or favorable groups after
decoding. Means over five fitted policies are descriptive, not independent
population replicates. No p-value or causal attribution is planned.

Authenticate the exact published parent receipt, all original closed phases,
source snapshots and payload hashes before any array decoding. Freeze this
protocol and complete source closure before qualification. Run only fabricated
tests and lint in qualification, then require its original native process to
close successfully. The producer opens the original BASE and prediction NPZs
and decodes exactly 17 arrays: IDs, true costs and 15 blind cost predictions.

After the producer closes, a separate audit opens those same two NPZ files and
decodes the same 17 arrays. It independently joins every saved JSON record to
the original case ID and true/predicted cost vectors. A separate pure standard
library auditor recomputes actions, metrics, category/bin partitions, all 60
group means, and all 20 paired contrasts. It reconciles blind MSE and regret
with all 60 previously published parent rows. Total scientific input accounting
is four NPZ opens and 34 array decodes across the two new phases. Neither
invokes a model, optimizer or world generator or reruns the original science
audit. This is independent saved-prediction analysis, not further training.

Use one registration and exclusive output paths, immutable source snapshots,
single numerical threads and the existing native supervisor. Qualification,
diagnosis and audit each have a fixed 120-second failure cap; sampled worker
RSS is limited to 3 GiB and phase outputs to 128 MiB. Original process closure
is required between phases. Retain partial evidence and stop on any failure;
no retry, threshold adjustment, case replacement or model selection belongs
to this registration. Publication uses only closed, audited scalar JSON and
opaque evidence, showing every paired seed. The parent 14/15 failure remains
visible regardless of the diagnostic pattern.
