## Equations, objective and state coordinates

With normalized current input `u`, the model computes `z=C_z*x+D_zu*u`, `w=NN(z)`, then emits `y=C_y*x+D_yu*u+D_yw*w` and advances `x_next=A*x+B_u*u+B_w*w`. There is no instantaneous `w -> z` algebraic loop. `NN` is `16 -> 64 -> 64 -> 8`, with ReLU after the first two affine layers and an identity final activation. Public `simulate(u,*,x0=None,offset=None)` returns `(y,t,x,w,z)`; output is physical, states/latent signals are internal, and `x` contains pre-update states. Preserve explicit `u[H,3,B]` and `x0[28,B]`, even for one request. [Model equations and public return](https://github.com/merijnfloren/freq-statespace/blob/a79e8c567b018a6c9462528fc1e10b77fd19b3e2/src/freq_statespace/_model_structures.py#L318-L452).

Training uses normalized period-averaged tensors `[N,3,R]`. The default offset is `ceil(0.1*N)`, hence **820 samples for N=8192**. The retained original `_bla` supplies a periodic steady-state initial vector at `x_bla[-offset]`; input tails are prepended, the warmup outputs discarded, and the remaining output RFFT compared with `data.freq.Y`. The unweighted objective includes **all RFFT bins**, not just `data.freq.f_idx`, and sums squared complex residuals scaled by `1/((N//2+1)*R)`. It is not our C100/H128 forecast loss or a claim of identical optimization objectives. Periodic tail warmup is appropriate inside FIT but must not be used to initialize a causal forecast. [Preparation and loss](https://github.com/merijnfloren/freq-statespace/blob/a79e8c567b018a6c9462528fc1e10b77fd19b3e2/src/freq_statespace/_nonlin_lfr.py#L536-L624).

The BLA optimizer applies a diagonal similarity normalization before and after its own fit. `connect` copies that final BLA coordinate system. **The inspected nonlinear optimization applies no further state-coordinate normalization or similarity transform.** It removes `norm` and `_bla` from decision variables, jointly updates all eight live matrices and network weights, and restores the original `norm` and `_bla` unchanged. Thus no hidden transform must be inverted to pass a vector into the final NL-LFR. However, the old BLA trajectory is only an initialization heuristic after dynamics change: equality of array coordinates does not make its state the correct nonlinear hidden state. A final-linear-submodel observability estimate is likewise a heuristic start for a separately specified context-only nonlinear solve. `_bla` is not a saved final-state posterior or the final linear submodel. [BLA normalization](https://github.com/merijnfloren/freq-statespace/blob/a79e8c567b018a6c9462528fc1e10b77fd19b3e2/src/freq_statespace/_best_linear_approximation.py#L406-L434), [restore original objects](https://github.com/merijnfloren/freq-statespace/blob/a79e8c567b018a6c9462528fc1e10b77fd19b3e2/src/freq_statespace/_nonlin_lfr.py#L271-L303), [retained BLA rationale](https://github.com/merijnfloren/freq-statespace/blob/a79e8c567b018a6c9462528fc1e10b77fd19b3e2/src/freq_statespace/_model_structures.py#L217-L288).

## Counts, resource risk and serialization

| Trainable part | Scalar count |
|---|---:|
| `A[28,28], B_u[28,3], C_y[3,28], D_yu[3,3]` | 961 |
| `B_w[28,8], C_z[16,28], D_yw[3,8], D_zu[16,3]` | 744 |
| NN weights `[64,16], [64,64], [8,64]` and biases `[64], [64], [8]` | 5,768 |
| **Total trainable** | **7,473** |

The 7,473 float64 weights alone occupy 59,784 bytes. This excludes normalizers, `ts`, request state and the retained original BLA. Count every retained numeric leaf or alias explicitly when exporting; `num_parameters()` does not measure resident storage. Default Optimistix BFGS stores a full inverse-Hessian PyTree with `7473²` entries: **446,765,832 bytes, about 426.1 MiB**, for that operator alone. Rank-update temporaries, compiled programs, nonlinear rollout differentiation and input buffers add memory. Shortening N does not remove this quadratic parameter cost. Full FIT entails 9,012 sequential steps per realization after warmup, with six pooled realizations; small-N timing cannot simply certify a 10,000-step empirical budget. [Parameter count](https://github.com/merijnfloren/freq-statespace/blob/a79e8c567b018a6c9462528fc1e10b77fd19b3e2/src/freq_statespace/_model_structures.py#L387-L392), [BFGS dense operator](https://github.com/patrick-kidger/optimistix/blob/v0.1.0/optimistix/_solver/quasi_newton.py#L42-L76).

The ZIP stores config plus Equinox leaves; the config identifies the network topology, bias, seed and `relu` activation. Export live matrices, the six layer arrays (`model.func_static.model.layers[i].weight/bias`, output-by-input orientation), four channel-normalizer arrays and `ts`; also retain original `_bla` leaves separately if used by the deployed estimator or needed for provenance. Qualify the NumPy forward equation against public `simulate` and confirm ZIP roundtrip equality, including `_bla`. Loading reconstructs the object, not BFGS restart state. Preserve raw stop flag and cap/failure independently; the [BLA runtime stop-status caveat](fsm-author-runtime-contract.md) applies here too. Freeze one fixture and its limits before execution. Keep **nx28/nz16/nw8/two width64 ReLU layers, seed42, sigma1e-4 and full BFGS**. Do not substitute an order-4 model, narrower network, frozen linear matrices, L-BFGS or Adam to obtain a passing runtime result.

1. Use N=8192, fs=6400, R=6, P=2, excited bins 1..3839, and the two deterministic full-rank DFT triplets from the earlier [qualification formula](fsm-author-runtime-contract.md), with N changed explicitly. Construct a known, active 28-state linear plant: `A_ii=.15+.7*i/27`, `B_ic=sin((i+1)*(c+1))/sqrt(28)`, `C_ci=cos((i+1)*(c+1))/sqrt(28)`, `D=diag(.1,.2,.3)` for `i=0..27,c=0..2`. Generate steady-state targets analytically in frequency space using `D_target=D+.02*I`, then duplicate periods. This deliberately nonzero fitting objective is only a runtime fixture, not evidence of nonlinear learning ability.
2. Compute synthetic-only normalization and construct the initial BLA28 directly in those coordinates: `B_norm=B*diag(u_std)`, `C_norm=diag(1/y_std)*C`, `D_norm=diag(1/y_std)*D*diag(u_std)`, with the same A. Require finite returned arrays and losses, exact trace-length accounting, unchanged original `_bla` and normalizer, and independently reconstructed output-spectrum loss no worse than the initial value. Preserve all failures and raw arrays. A cap reached without the stop condition is a partial optimization, not convergence.

One dense inverse-Hessian alone is already 426.1 MiB; host memory availability must accommodate substantial extra allocation.
