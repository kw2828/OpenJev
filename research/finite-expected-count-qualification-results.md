# Expected-count numerical qualification

**PASS: 66 tests, lint and seven independent exact hidden-path witnesses.**
This establishes numerical prerequisites for a learning experiment. It is not
a decision-performance or generalization result.

Forward-backward inference and expected counts were compared with independent
rational enumeration on two-state fabricated cases of up to three actions.
Checks cover action-conditioned transitions, emissions, found/survival hazards,
uniform resets, early terminal events, impossible observations, zero-exposure
updates, padding and owned arrays.

The implementation supports MLE and explicit MAP updates. The learning study
uses pseudocount **0.001**, equivalent to the stated log-prior objective. The
Torch gradient and NumPy expectation paths share that objective. Finite-logit
imports preserve the represented probabilities without clipping.

The retained witness applies three updates per method to eight fabricated
histories. Both preserve the cost-head bytes and improve their stated objective.
Those fixed update counts are not compute matched. Test model calls are not
fully instrumented; no empirical dataset or scientific checkpoint was loaded.
No scientific TRAIN or DEV cases were generated.

The original numerical phase completed in **3.518 seconds**, with 21 pinned
sources and nine retained payloads. The later complete integration qualification
passes **156 tests** and covers stage deadlines, persistent Adam state, rollback,
original qualification admission, producer integration and independent audit
mutations. It is a separate registration.
