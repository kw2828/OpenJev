## Evidence and reproduction limits

`MANIFEST.json` records every other archive member's hash and size. The separately
published `SHA256SUMS` checks the compressed archive. Packaging does not decode
numerical arrays, parse trajectory journals or call any model. Original paths
and records are preserved, including the initial renderer qualification's failed
combined lint command and the subsequent renderer-specific successful check.

This is **not a self-contained executable reproduction**. `DEPENDENCIES.json`
names the eight external native inputs with original hashes: the base and shifted
public kernels, the previous native qualification plan/receipt/terminal, tensor
metadata, extracted teacher tensors and original H5 teacher weights. Their bytes
and the installed native/general Python environments are not bundled. Even the
saved-audit authentication code requires these native input hashes while making
zero native calls. Upstream provenance is in
`research/otto-learned-reference-and-symmetry.md`.

Historical records contain the original absolute paths and runtime versions.
A relocated reproduction needs a distinct plan and fresh outputs. Rewriting the
original receipts would break their identity. Root and OTTO license notices are
included and must accompany redistribution of the associated source.
