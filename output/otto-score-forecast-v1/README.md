repository root to restore paths. Gzip journals are preserved as original bytes;
the metadata stop report does not certify their internal completeness or replay
their records. No failed episode is repaired or credited as complete.

Inherited teacher/runtime dependencies and historical inputs remain identified
by path and hash in the original plan. They are not a standalone runtime bundle.
The absolute-path authenticators remain unchanged, and restoring these files
does not qualify a scientific retry or authorize new fitting.
