completed. The auxiliary loss improved both architectures, but the proposed
correction did not consistently outperform the ordinary GRU and lost full-path

scientific source changed after the 136-file precollection freeze. The early
metadata-only plan rejection, unexecuted metadata-review draft correction and
initial Git credential failure remain in the record.

The independent audit reconstructs the saved metrics and all 55 conditions.
It does not rerun model inference, training gradients, teacher outputs or timers.

Auxiliary fits cost approximately 1.9 times their corresponding original-loss
fits. The prior MSE is a score diagnostic, not probability calibration.

Fixed-path forecasts establish no autonomous effectiveness, learned world model,
reinforcement-learning improvement or biological-wiring advantage.
