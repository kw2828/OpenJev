# Stage 2 implementation review

**Source-based adaptation map only; unexecuted and contingent.** This note performs no preparation, target generation, fitting, model inference, native episode or evaluation. Stage 2 requires successful completion and independent audit of the fixed collection, followed by its own qualified implementation and frozen execution plan. It changes neither the [held coverage protocol](../../research/otto-coverage-protocol.md) nor any closed scientific source or result.

1. **Separate arm identity from learning mode.** In [`fit_one()`](../../scripts/study_otto_bellman_control.py#L470), use `family=teacher_only|mixture` for filenames and records, but always call `continue_learning(..., mode="backup")`. The old implementation conflates those two concepts.

2. **Keep two canonical datasets.** Replace [`prepare()`](../../scripts/study_otto_bellman_control.py#L408), whose target/episode checks assume completed teacher trajectories. Both datasets retain float32 features, float64 beliefs/sensing lengths, int64 positions, public eligibility and exactly 5,589 canonical rows. Mixture rows have no MC labels. Bind `dataset_id`, dataset hash and row identity throughout target/checkpoint/order records.

3. **Guard placeholder exclusion through provenance.** The unchanged [continuation core](../../src/openjev/research/otto_bellman_learning.py#L210) temporarily creates a placeholder tensor, then replaces it before epoch-one optimization. Add a caller-hook guard before every optimizer attempt: require backup mode and a completed, saved refresh for epoch `1 + 5*((epoch-1)//5)`; require exact materialized float64/float32 target agreement and the current dataset/checkpoint join; reject an MC `targets` event. Test refresh failure and publication failure both prevent the first update. Do not reject numerically zero backup targets: provenance distinguishes valid zeros from placeholders. The audit can verify the saved provenance and event ordering; actual optimizer consumption additionally remains bound to the reviewed, immutable continuation implementation.

4. **Change audit routing and diagnostics deliberately.** [`audit_targets()`](../../scripts/study_otto_bellman_control.py#L636) currently always uses `self.full_training`. Route it by family; both datasets have indices `0..5588`, so indices alone cannot catch the wrong input. Keep [`predict_final()`](../../scripts/study_otto_bellman_control.py#L610) on common original teacher TRAIN/VALID if retaining MC diagnostics. Never report mixture-placeholder MSE. Neither those descriptive MC errors nor self-target losses replace autonomous action evaluation.

5. **Update fixed work and closure.** Six fits require **48 refreshes, 268,272 sixteen-row forwards, 4,292,352 branch values and 10,560 updates**. Save 48 target checkpoints plus 48 target payloads; remove three obsolete MC-target files. Reuse unchanged [`FrozenValue`](../../src/openjev/research/otto_return_value.py#L197), explicit branches and episode mechanics. Replace hardcoded family names in aggregation, evaluation order, completion checks and payload inventories. Qualification, parity, diagnostics and independent numerical replay remain additional, separately counted work.

6. **Keep costs assigned correctly.** Adapt [`amortization()`](../../scripts/study_otto_bellman_control.py#L696) to `U + (L + common_preparation/6 + family_preparation/3 + D + mixture_only*C/3)/H`. Define disjoint preparation scopes so collection reconstruction/selection is not charged twice. Preserve head loading `/144`, shared deployment setup `/1296`, physical totals and separate audit costs. `C` is incurred once physically and allocated only to the three mixture fits. The fixed `H=1,100,10000` scenarios are accounting views, not additional executions or a substitute for the deployed-cost comparison.

The Stage 2 decision remains **all 42 conditions**: 18 competence conditions require every mixture fitting seed in every setting to reach at least 95% weighted success and at most 1.05 times analytic capped moves. The other 24 conditions compare the mixture family against teacher-only backup and unchanged references in each setting: no lower success, capped moves at most 0.95 times the comparator, at least six of eight strictly positive paired block gains, and no greater complete deployed controller time. Use unrounded values without a decision epsilon. Technical completion, parity and independent agreement are separate prerequisites. No architecture, recurrence, connectome or novelty claim follows from this implementation map or from fitting alone.
