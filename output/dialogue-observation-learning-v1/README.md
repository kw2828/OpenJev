# Observation learning input evidence

Code is MIT. Derived observations originate from the
[Schema-Guided Dialogue dataset](https://github.com/google-research-datasets/dstc8-schema-guided-dialogue/tree/e852981ae34990f4358979625854259302feaa78),
licensed CC BY-SA 4.0. Retain that attribution and license for dataset content.

The complete prepared plan, source pins, aggregate workload profiles, index,
paired orders, largest-batch metadata and receipts are published. Reversible
actor tokens, target rows, literal registers and the two lexical arrays remain
local under the original dataset protocol. Completion manifests describe the
full local closure, not the Git file membership. Their exact byte counts and
hashes bind all omitted payloads; the versioned preparation reconstructs them
from the authenticated public inputs and pinned local tokenizer.

`failed-preparation-publication-01` preserves the first attempt's source and
failure receipts and hashes all partial local files. The initial version was
not resumed or overwritten. The additive V2 corrected only the false requirement
for globally unique bare dialogue IDs. `preparation-02` is its separate,
completed execution. `preparation-audit-02` is an independent saved-data audit,
with no neural execution or quality scoring.

The tiny synthetic preflights preserve their original failures and narrow
corrections. They establish implementation behavior, not empirical efficacy.
