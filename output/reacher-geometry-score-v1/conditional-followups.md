# Conditional follow-ups: learning what the controller needs

Primary-source review, 2026-09-18. Prospective, unfrozen and unrun. This note was written while the geometry-scoring study was active. No live execution, intermediate result, score file or unfinished audit was read. No model, training, native-environment or evaluation calls were made. Only this memo was written; the frozen experiment is unchanged.

**My priority is to identify which decision error remains before changing the architecture.** A model can predict angles accurately while ranking candidate actions poorly. Conversely, a deliberately incomplete state model can support good decisions. The literature already makes both points. Neither task-oriented prediction nor recurrent state is a novelty claim by itself.

## Completed prior context and what remains uncertain

The completed memory comparison qualified under its original gate. The subsequent explicit-cache comparison failed its stronger persistent-memory gate, passing 15/28 checks. The cached MLP had lower mean native cost than the persistent GRU in all three panels and every paired fit. That is evidence against escalating recurrent complexity under the tested recipe; it is not proof of universal cache sufficiency or model equivalence. See the [independent cache review](../reacher-cache-ablation-v1/independent-results-review.md), bound to parent plan `7868daa12242df37f020946f9d3b279811a0e97547eef4d8b179da6e9394cefa` and audit `d1a6e486fde8823f5a760af8036e79af4fc57b452bc5fa0c8d184093ce2a1790`.

The completed [reward diagnostic](../reacher-memory-ablation-v1/reward-bottleneck-diagnostic.md) found much larger relative angle-prediction gains than control gains, with most selected-action reward error attributed to the learned distance residual. This was observational analysis of completed outputs, not a causal test of the scoring head. Final-angle forward kinematics also differed slightly from native RK4 cached-body reward timing. The running experiment tests one approximate scoring replacement while freezing the transition models; its result is unknown to this note.

The [earlier mechanism review](../reacher-cache-ablation-v1/next-mechanisms-review.md) already covers KalMamba, Gated DeltaNet, Skip RNN, ACT and Backpropamine. This note does not repeat those proposals or add biological wiring to an unresolved prediction-versus-control problem.

These are precedents, not evidence that any particular follow-up will work. The experiments below are our proposed adaptations.

## 1. Fit the scalar decision interface while keeping dynamics frozen

**Use this branch if** the completed geometry intervention improves both finite-bank ranking and fresh native control, or if its diagnostics specifically indicate that poor scalar ranking remains a plausible bottleneck. A diagnostic-only improvement does not qualify a new controller.

Keep all six inherited students, their public-history semantics, decoded trajectories and planner fixed. Fit a small finite-horizon return readout with stopped gradients into the student. Give the readout the same fixed-length representation in both model families: predicted angular trajectory, issued candidate commands, public target, actual validity/age, horizon mask and public time remaining. Compare return regression with the same head trained by return regression plus a fixed pairwise-ranking term. Retain the original reward-head score and the approximate geometry score. This isolates the scalar objective and extra readout capacity; it does not train a new recurrent world model.

An ordinary trajectory supplies outcomes for its issued actions only. It cannot label unexecuted candidates. If counterfactual ranking labels are needed, separately authorize and freeze a small training-only native branch bank. For example, 64 training roots x16 fixed sequences x4 common noise branches x12 steps means at most 49,152 native transitions. Select roots from training episodes before fitting and keep entire episodes disjoint from calibration and fresh evaluation. All head variants receive exactly the same branch labels, candidate bank, initializations, update order and fit budget. Native state is used to generate labels, never as a readout input. Do not repurpose the currently exposed evaluation roots as an untouched test set.

Choose the score target explicitly: either the complete native return, or native distance return plus one fixed expected actuator-cost term. Do not train on total reward and then subtract actuator cost again. Preserve the declared clipping convention rather than silently mixing clipped training returns with unclipped claims. A lower native-return MSE and a better rank can disagree, so report both along with selected native return and finite-bank regret.

**Controls and continuation.** Keep cached MLP as the simplest established baseline and persistent GRU as the comparison. Same-size heads, same data and paired initialization distinguish objective from capacity. Report equal-candidate results and a separately profiled equal-total-compute comparison that charges every head, decoder, branch copy and training label. Continue only if a prospectively fixed utility margin holds on new ordinary and shifted episodes across all paired fits without a material full-sensing regression. A scalar-head gain would support improving the decision interface, not prove value equivalence or biological novelty.

## 2. Test whether a short rollout plus terminal value beats longer prediction

**Use this branch if** short-horizon candidate ranking is credible but closed-loop utility remains weak, suggesting finite-horizon planning rather than immediate reward prediction. The diagnostic is suggestive only; this hypothesis needs a separate matched comparison.

Start with frozen students and a small terminal head, not joint TD-MPC2 training. A conservative first target is the remaining logged return under the training collector. Construct its input by causally reconstructing a training root and advancing through the next H logged issued actions without assimilating future observations; give the head the resulting imagined state and known remaining episode length. Its label is the actual logged return after that endpoint. Split by episode. Fit targets and the baseline head on identical data; clamp the terminal value to zero at the actual terminal boundary.

This is a **behavior-continuation value**, not an optimal critic. The collector's mixture of policies and future sensing affects that target, and planned states can differ from logged states. Report these limitations. Do not silently replace the target with a max-over-actions TD backup: that introduces off-support optimization and a separate offline-RL method. A new fixed-policy native continuation dataset is an alternative, but must be declared as extra paid supervision shared by all variants.

Compare H=6 with no terminal value, H=6 plus the head, and H=12 without it; include a constant/time-only terminal predictor to catch superficial episode-length effects. Use the same per-step score selected prospectively for every variant. Retain the strongest cache model and all recurrent fit pairs. First report equal candidate counts; then profile a total-compute budget and adjust candidate counts before fresh evaluation. Multiplying horizon by candidate count is insufficient because terminal calls, state copying and CEM adaptation also cost time. Do not change the existing frozen CEM study to run this comparison.

**Continuation.** Require a repeatable native utility-versus-compute improvement and useful held-out terminal-value calibration, not merely smaller state error. If a behavior-value head cannot help, do not infer that joint TD learning would necessarily fail, but do not expand to a larger architecture on that evidence. Joint task-weighted dynamics, a policy prior and online collection become justified questions only after the simpler value interface has demonstrated a benefit. VaGraM supplies a conventional objective baseline for that later step.

## 3. Measure uncertainty in the action comparison, then decide whether to pay for it

**Use this branch if** completed diagnostics show unstable candidate ordering or systematic optimism on the scenario shift. High angle variance alone is not enough.

For candidate sequences a and b at one public root, the relevant variable is their return difference, Delta=R(a)-R(b). Evaluate differences under common noise so shared variation is preserved, rather than adding two marginal variances and assuming independence. Separate variation across outcome branches from disagreement across fitted predictors. Start with a conventional ensemble-mean scorer and an explicitly declared conservative scorer; retain a single-model scorer, a simple age/observation-innovation rule and uniform random allocation of the same extra budget. A small ensemble of fitted heads measures head uncertainty only and can miss shared dynamics errors; state that scope.

First establish that a fixed, more expensive scorer actually improves native utility on a calibration partition at some cost. Only then consider allocating it selectively according to a public estimate of expected action-regret reduction. Raw ensemble variance, predictive entropy and observation age are competing gate inputs, not proof of reducible error. A large irreducible actuator disturbance can make outcomes uncertain without making extra model computation useful.

**Controls and continuation.** Use cached MLP plus a simple two-valid-observation feature model as explicit-history controls before attributing benefit to recurrence. The latter stores actual measured angles, their actual separation in time, validity/age and issued-action history; it must not insert imagined observations into the real cache. Wrap angular differences and distinguish interval-average motion from current velocity. Its feasibility details are already in the [two-observation design](../reacher-cache-ablation-v1/two-observation-design.md).

Calibrate any gate or penalty on separate episodes, freeze it, and assess fresh native control under a fixed total compute budget. Charge ensemble fitting, all model samples, gate calls and slow-path invocations. Compare always-fast, always-slow and matched-rate simple gates. A calibrated return-error interval does not itself guarantee closed-loop safety, coverage under scenario shift, or improvement from extra compute. Continue only if the utility-compute frontier improves over these controls. Otherwise retain the simpler controller and report that uncertainty estimation did not buy useful action selection.

## Common stopping and interpretation rules

Keep the current study's full gate and every failed prior result intact. These proposals are not permission to inspect its partial outcomes, tune against its evaluation cases, select a favorable fit, or adjust its thresholds. Choose at most one follow-up after its completed audit, freeze the numerical margin and budget, and retain all paired fits and reference competence checks.

Fresh seeds in the same repeatedly studied simulator improve separation from the immediate development set, but they do not make the project an independent external confirmation. Treat new Reacher results as development evidence; a stronger paper needs a predeclared transfer task or independently held-out environment after the mechanism survives conventional controls. Native hidden state, realized future actuator noise and future observations remain audit/training-label information, never online policy inputs.

There is no present basis to add a connectome. A biological claim would require a particular state-update or learning rule with a measurable advantage beyond cache/history and ordinary recurrence, followed by topology controls. A task-relevant value signal could eventually modulate an already useful recurrent correction, but that would be a later mechanism experiment. The immediate choices are better scoring, better planning horizon allocation, or useful uncertainty about decisions.
