# Independent review: explicit angle-cache comparison

Status: prospective design review only. No training, model inference, native simulation, scientific RNG draws, protocol freeze, or execution was performed for this review. Only this memo was written. The reviewed design is [cache-control-design.md](../reacher-memory-ablation-v1/cache-control-design.md); the completed parent result is [the memory report](../../research/reacher-memory-ablation.md).

The proposed five-arm comparison is worth implementing: persistent residual GRU, reset-and-encode current GRU, cached-angle GRU, current-packet MLP, and cached-angle MLP. It tests whether a small explicit store of public measurements explains the persistent model's advantage under the existing training recipe. It does not yet test velocity inference, biological wiring, or a new world-model mechanism.

## Material scientific issues before freezing

1. **Keep the reset-and-encode current GRU.** The frozen current GRU resets hidden state and then uses a measurement-validity gate. On missing packets its hidden state is exactly zero. The proposed cached GRU encodes at every real root, including missing ones. Without a current GRU that also encodes at every root, the comparison changes both information and the missing-root computation. The old gated arm remains historical context, not the matched current control for this experiment.

2. **The strongest contrast is within each architecture.** Match all initial tensors between the current and cached GRUs; match all initial tensors between the current and cached MLPs. The persistent GRU can share the same GRU initialization. With eight input features the GRU schemas remain identical, and the two MLP schemas remain identical. Do not give current and cached MLP separate initialization streams. The MLP's different transition architecture is still a confound for cross-family comparisons despite its close parameter count.

3. **An explicit angle cache is memory.** It can retain a measurement throughout an arbitrarily long gap. Call it a last-valid-angle baseline, not a memoryless or strict-window baseline. The intended mechanism is retained measurement content plus actual availability/age. It must not additionally retain learned hidden values, old predicted angles, a previous action feature, velocity, nominal dynamics, or another information-bearing counter supplied to the encoder. Integer phase/index fields used to validate execution are administrative state, not additional model inputs.

4. **Shared CEM randomness is not identical complete proposals.** Every arm must receive the same initial bank and per-stage innovation arrays for a paired case. Later CEM proposals depend on that arm's saved scores and therefore can legitimately differ. Reconstruct each arm's complete adaptive search independently. Identical selected actions or later-stage banks are not a required pairing invariant.

5. **Full sensing is not full physical state.** Velocity remains hidden. The prior persistent model already gained 7.35% over the gated current GRU with full sensing, compared with about 9% on gap panels. A new gap-panel win alone does not identify gap bridging or velocity estimation. Report full, six-step and ten-step panels, and distinguish the full-panel advantage from the additional gap-panel advantage. A descriptive difference of differences is useful but is not a clean intervention on hidden velocity, because policies change their own trajectories.

6. **Do not turn a failed superiority test into proof that caching is sufficient.** If the persistent continuation gate fails, report failure or inconclusive evidence for residual recurrent advantage. A claim that caching closes the practical gap needs a separately frozen equivalence/noninferiority margin and supporting paired evidence. Compare persistent recurrence with both cache GRU and cache MLP; do not select whichever cache comparator is weaker after seeing results. Report current-to-cache changes for each family separately.

7. **The unchanged loss remains a deliberate limitation.** `sequence_loss` supervises one-step observations only at genuinely observed endpoints and its open-loop observation/reward windows only from genuinely observed roots. A usable cached feature does not make a missing root observed. This preserves the previous recipe but does not directly optimize multi-step planning from missing roots. Any persistent/cache difference therefore combines representation and optimization under that fixed recipe, not information capacity alone. Keep the recipe fixed for this comparison and state that limitation; changing masks would be a different study.

8. **Equal updates are not equal computation.** Cache validation/copying and feature construction cost time. The persistent GRU also backpropagates through a longer parameterized real prefix, whereas explicit caches carry raw measurements. All real roots, all imagined advances, selected-action re-advances, bookkeeping, state payloads, fitting/restoration and serialization need accounting. Existing affine-operation formulas omit these costs and are estimates, not FLOP matching. Keep the physical references descriptive because their supplied dynamics and 64-proposal search differ from learned CEM256.

The five-arm plan implies 15 fresh fits and, with the same five references on three panels, 60 complete control rows: 45 learned plus 15 references. At 64 cases and 50 steps this is 192,000 control transitions. With the unchanged 768-episode inherited corpus and 96 fresh prediction episodes, ordinary native replay would cover 235,200 transitions, before separately counted public-observer replay. These are prospective coverage arithmetic, not completed work.

## Minimum independent engineering checks

These checks should use synthetic public packets and dedicated engineering namespaces, not any scored checkpoints or cohorts.

| Check | Independent expected behavior |
| --- | --- |
| Same-weight full-observation parity | Current/cache GRU outputs agree exactly on a fully observed history; current/cache MLP outputs agree exactly too. Compare features, hidden where applicable, and same-action imagined predictions. This is a pretraining semantic invariant, not a requirement that differently trained final weights coincide. |
| Older-history invariance | Two legal prefixes with different older packets/actions/hidden/predictions but identical current packet and last observed angle/time yield identical cache root features and same-weight output. Current controls additionally ignore differing last-angle caches. |
| Public-only cache update | At step `t`, latest index `j` is the greatest actual-valid index at or before `t`; cached angles equal that public packet's four angle components. Missing placeholders, including nonfinite poison values, cannot update it. The actual stored public packet still has zero angles when missing. |
| Age and startup | Initial observation is valid; zero age then. Subsequent age is consistent with `(t-j)*dt`, with a tight declared tolerance for float32 representation. Reject missing starts, stale/nonmonotone phase, target changes, or inconsistent age. Use an integer last-observed index as the authority rather than repeatedly incremented float time. |
| Boundary and branch purity | Real assimilation is permitted at initialization or after exactly one selected advance. Candidate expansion makes independent copies. No advance changes actual cached measurement or its timestamp. Multi-step candidate state cannot be assimilated as real state. Reversing candidate order cannot mutate root/cache. |
| MLP imagined-state boundary | First imagined advance uses the declared current/cache feature vector; later advances can use its newly predicted unobserved packet. Those predictions never refresh the actual cache. At the next real assimilation all prior predicted angles are discarded. |
| Gradient and loss-mask boundary | Synthetic changed future/missing labels cannot leak into earlier roots. Cache values contain no learned graph from old hidden/predicted values. Actual-valid target/root counts match the unchanged public masks, even while the cache supplies nonzero missing-root features. Nonzero parameter gradients and exact paired initial tensors are verified. |
| Both gaps and terminal step | Exercise six and ten missing decisions, reappearance, differing per-case gap phase, final root 49 and terminal packet 50. Do not assimilate an unneeded terminal packet, wrap an episode, or advance a real history twice. |
| Actual checkpoint class | Same-shaped weights from the wrong current/cache mode or class must be rejected. Bind feature order, mode, age/cache rules, dt/noise, residual reward, source/runtime, initial payload and minibatch order. Corrupt the final fit's checkpoint and verify that no evaluation collection/inference begins. |
| Failure/cost accounting | Reject a post-completion cap overrun, preserve partial native episodes and failed receipt, and never silently resume or omit a fit. Hook-observed affine calls agree with claimed sample counts; actual cache tensor bytes and whole-row time remain reported separately. |

The cache's public-history recurrence can be recomputed numerically by an independent saved-output auditor without a learned model. Learned hidden vectors and score predictions cannot be independently established from those cache invariants. Preserve this distinction in every audit receipt.

## Saved arrays needed for a real cache audit

Retain the existing native episodes, issued actions, executed predictions, all CEM chunks/raw scores/selected IDs, and root/carried state arrays. In addition to the actual packet and any hidden vector, save the explicit last-valid-angle cache, its actual decision index, the real decision counter, and the branch/phase depth wherever the new model uses them. If the encoder input is stored separately, save its exact eight features too. If it is not a state field, the audit can reconstruct the expected feature vector but cannot independently show that the learned encoder consumed it; source and unit tests remain the evidence for that mapping.

For every case and root, independently reconstruct `j=max{s<=t: packet[s].valid=1}` from the saved public history. Check root cache equals public angles at `j`, last-valid index equals `j`, current index equals `t`, and age agrees with elapsed physical time. Root public packet must equal the actual sanitized packet, not a fabricated cache-as-measurement packet. Check the carried cache/index are unchanged after the selected action and its branch depth is one. Check root/carried hashes, integer and float dtypes, lengths and byte counts. Do not assume every auxiliary state field is float32 or every carried packet is sanitized: imagined predicted packets intentionally contain predicted angles with validity zero.

For the reset-and-encode current GRU, **remove the old requirement that missing-root hidden values equal zero**. They are generally nonzero under its new encoder. Numerical hidden recomputation would require a declared learned-model audit and is outside the saved-output-only scope. For persistent GRU, the existing missing-root hidden equality to the previous selected-action carried hidden remains valid.

## Reporting decision

Report every fit and both within-family cache gains, all panels, the two cached comparators against the designated persistent model, and supplied-physics references. No best-family or best-pair replacement. Save every gate comparison and conditional interval even when they disagree. Retain current-to-cache negative effects and any compute disadvantage.

A persistent win over both trained cache comparators would support information beyond a single stored public angle measurement under this recipe. It would still not identify velocity estimation; two public measurements, action history, optimization, or other latent information could explain it. A strong cached MLP result would be especially informative given its close utility in the preceding study. Neither outcome by itself establishes architectural novelty or general robotics transfer. The two-measurement motion feature comparison remains a distinct later experiment, not an unplanned sixth arm or a rescue after a failed continuation rule.
