Paired action-effect supervision improved action-effect forecasts but worsened shifted decisions against the identical recurrent control. The prospective mechanism rule failed 6/18 comparisons; the unchanged legacy forecast rule also failed 6/18. All six complete comparisons against the matched recurrent control failed.

Twelve compact models used the same 1,046 parent TRAIN cases and 181 fresh DEV cases across two sensing settings. Every arm received both action branches, the same optimizer updates and three training rollouts per batch. Only the candidate weighted the signed action-effect loss.

Across three-fit means, compared with the matched recurrent control:

- Long action-effect error fell 22.78% / 19.44% in the base/shifted settings, improving in all six paired seed-setting comparisons.
- Long decision gap fell 12.34% in the base setting but rose 19.79% after the sensing shift. All three shifted decision comparisons worsened.
- Normal-observation decision gap rose 8.51% in the base setting and fell 6.54% after the shift.

The independent audit reconstructed all 24 forecast views, 12 paired action-effect views and both gates. All three original processes completed, were reaped and stayed within their registered bounds. Qualification passed 303 fabricated tests and lint; the earlier formatting-only failure is preserved.

New collection, fitting and audit worker time totaled 260.272 seconds. The charged parent acquisition adds 306.723 seconds, for 566.995 accounted worker seconds. This includes unused parent DEV acquisition cost; qualification, publication and historical pretraining are outside that total.

The archive contains the registered source and direct inputs, original process receipts, reused TRAIN and fresh DEV arrays, all twelve final checkpoints, forecasts, independent audit, plots and README media. It excludes parent DEV/prediction/checkpoint arrays. Installed NumPy source evidence and licenses have portable archive paths; environment installation and older authentication dependencies are described in the manifest.

This is a supervised forecasting and teacher-imitation experiment. It establishes neither autonomous-control gains nor a new architecture, biological-wiring advantage or RL algorithm. The failed comparisons remain visible. The proposed next diagnostic asks how much teacher-decision information is unavailable during observation gaps; it has not been executed.
