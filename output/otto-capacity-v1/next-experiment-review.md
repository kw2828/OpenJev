# Conditional next experiment after the capacity screen

**Prospective review, written before capacity outcomes.** No qualification or active study metrics, predictions or trajectories were opened for this note. Every branch below requires a separate frozen protocol; none changes the current twelve conditions or selects a winning family after the fact.

The audited [Bellman comparison](../../research/otto-bellman-control-results.md) failed 19/42 conditions, including every absolute competence condition, despite improvement over weak learned controls. The earlier [symmetry study](../../research/otto-symmetry-head-results.md) already tested pooled student-state training and failed 2/54. Thus neither larger networks nor coverage is an established remedy. The primary benchmark used three 1,024-unit hidden layers together with Bellman learning and exploratory collection, motivating separate tests of these factors rather than attributing its result to width alone. [Loisy and Heinonen, Algorithm 1 and Table 5](https://auroreloisy.github.io/papers/Loisy2023a_EurPhysJE_drl-benchmark.pdf).

| Audited capacity outcome | Priority and smallest informative follow-up |
| --- | --- |
| Incomplete qualification, numerical disagreement or runtime failure | Resolve that engineering issue in a new preserved attempt. No scientific comparison or model selection is available. |
| Both wide families satisfy all twelve conditions | Test whether the scalar gains survive action selection. Qualify the explicit sixteen-branch readout, then run a small fresh, paired autonomous comparison of all nine fixed final checkpoints plus analytic control. Do not retrain, select a seed or drop either wide family. Charge complete control cost and bound the workload before rollout. This tests transfer from regression capacity to decisions, not novel architecture. |
| Wider models reduce TRAIN excess but fail the VALID requirement | Do not add still more capacity or call this a memory failure. Generalization, target noise and coverage remain possible. The smallest data intervention is the existing [coverage proposal](../../research/otto-coverage-followup-design.md): one fixed ordinary MLP and backup procedure, teacher-only versus one frozen mixture of teacher and fresh student TRAIN states, identical total rows and update counts, with unchanged and analytic controls. Both arms generate their own backup targets. This tests coverage within that procedure, not common-target architecture quality. |
| All families retain substantial TRAIN excess above the empirical alias floor | Test optimization geometry before recurrence. Compare raw features with one prospectively fixed, invertible spatial/context block scaling, using the same ordinary network, targets, rows, seeds and updates. Match the initial represented function by compensating the first-layer weights; compute the common `c0*mass` skip from unscaled mass. Fold the scaling into the exported first layer for readout. A gain would support conditioning of this fitting procedure, not extra information or memory. |
| TRAIN error is close to the observed alias floor, or wide-family improvements are inconsistent | More width cannot be inferred to be the remedy. Report the actual floor and signed excess, keep the failed twelve-condition decision and all seeds visible, and avoid choosing the better wide family. Any repeated-outcome target study would require fresh TRAIN-only collection and a separate budget; the finite-cohort floor is not a population noise estimate. |

“Substantial” and “close” above are interpretive descriptions, not new executable gates. Any numerical threshold for selecting a subsequent experiment must be frozen separately before its new data. Better VALID MSE alone never demonstrates correct successor-branch rankings or competent search.

If a fixed scaling control still cannot fit the common labels, the next spatial test should compare a small CNN, a parameter-matched ordinary MLP and the same CNN receiving a fixed permutation of grid locations. Keep the public information, targets and training exposure identical. The permutation control distinguishes useful spatial adjacency from convolutional parameter sharing or capacity. Do not combine this first test with new coverage, target recipes or recurrence.

Recurrence is a later state-estimation/compression hypothesis: this task already supplies a model-based full public posterior. Readout failures therefore do not establish missing historical information. A recurrent proposal should first demonstrate a memory or computation opportunity against the full filter and a dense recurrent control, then test fresh autonomous control. A connectome-specific claim additionally needs matched dense and shuffled or degree-matched wiring controls. Neither direction is ruled out by the existing failures; neither is admitted by scalar fitting gains.
