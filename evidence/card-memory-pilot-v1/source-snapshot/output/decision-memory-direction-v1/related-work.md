# Decision memory: overlap audit and one learned pilot

**Prospective source review, 19 September 2026.** No environment, model, training, seed allocation, or existing-source changes were performed. The failed Mystery Path recipe remains closed. This proposes a direct learned-memory experiment on a different, established environment, not another task-admission exercise or a novelty claim.

**Recommendation:** test a small, explicitly experimental extension of diagonal Kalman associative memory: reopen uncertainty in the current key's coordinates when its prediction is wrong. Compare with a diffuse update matched for immediate effective write gain, ordinary KDN, and conventional recurrent memories. This is a falsifiable interference hypothesis, not an established new architecture.

## Three papers establish substantial overlap

Use the convention `S[key_dimension, value_dimension]`, with read `S.T @ q`.

| Pinned primary source | Established mechanism and overlap | Limit on the proposed claim |
| --- | --- | --- |
| [Yang et al., DeltaNet, arXiv:2406.06484v6](https://arxiv.org/html/2406.06484v6#S2.SS2), 15 January 2025 | `e = v - S.T @ k; S += beta * outer(k,e)`. This is already the error-corrective write in yesterday's conditional proposal. The paper develops efficient parallel training and studies retrieval/language modeling. | Replacing additive writes with this rule is a conventional ablation, not a new architecture. Parallel GPU training results do not establish tiny sequential CPU throughput. |
| [Bui et al., Kalman Delta Networks, arXiv:2609.07816v1](https://arxiv.org/html/2609.07816v1#S4.SS1), 7 September 2026 | Diagonal prediction `p_hat = alpha²*p + omega`; gain `g = p_hat*k / (r + sum(p_hat*k²))`; mean update `S = S_hat + outer(g,e)`. The reverse-KL diagonal posterior has `p = 1/(1/p_hat + k²/r)`. Its additional information-scaling variant changes that precision increment. | Uncertainty-dependent residual writes, covariance tracking, and diagonal approximations are explicit prior art. The exact posterior-mean statement is conditional on the retained diagonal prior and linear-Gaussian model, not a general calibration guarantee. Large language-model results do not establish decision utility here. |
| [Cui, HOLA, arXiv:2607.02303v1](https://arxiv.org/html/2607.02303v1#S3.SS3), 2 July 2026 | Adds a bounded exact KV cache to gated delta memory; retains the highest write-time scores `beta*norm(e)` and uses a separately normalized sharp cache read. It includes a matched recency-cache comparison. | An error-prioritized exact cache, a fast/slow memory split, or hippocampal terminology would not make our proposal novel. Reported evidence concerns language/retrieval. It does not establish a biological-connectome or native-control result. |

The second and third papers are recent v1 preprints. This bounded three-paper screen cannot establish novelty by absence. Do not stack covariance, surprise caching, biological names, and a new decoder and call the combination a contribution. Innovation-adaptive filtering also has a broader prior-art history not exhausted here. Yesterday's error-corrective proposal is directly covered by DeltaNet; adding uncertainty or surprise storage alone does not escape that overlap.

## One existing native benchmark

Use **`popgym-ConcentrationHard-v0`**, pinned to official POPGym commit **`410d5aa626dae8024f498354d8781a0d1870c399`**. The [registered environment](https://github.com/proroklab/popgym/blob/410d5aa626dae8024f498354d8781a0d1870c399/popgym/envs/__init__.py#L226-L230) uses a shuffled 52-card deck, 13 ranks, and a 104-action limit. Public observations identify face-up card positions/ranks; actions choose a position. A match rewards `1/26`; a failed pair incurs `-2/104`. This provides a native decision return alongside associative retrieval. [Official environment source](https://github.com/proroklab/popgym/blob/410d5aa626dae8024f498354d8781a0d1870c399/popgym/envs/concentration.py).

Critical boundary: `step()` constructs the returned observation **before** it resolves/discards the current pair. A mismatched pair therefore remains visible in that returned frame even though the internal next phase is empty. Track phase from issued actions and public reward, not by assuming every visible card is permanently matched. A query must precede the selected card's returned reveal. Never call `get_state()` or inspect the shuffled deck for actor features or training labels. Write one issued-action/reveal event, rather than repeatedly writing every already matched card in the observation. These are implementation requirements, not changes to the task. [Step/reset methods](https://github.com/proroklab/popgym/blob/410d5aa626dae8024f498354d8781a0d1870c399/popgym/envs/concentration.py).

The current package declares only NumPy and Gymnasium as mandatory dependencies and has an MIT license. A compact CPU implementation is plausible; actual runtime remains to be measured. We need no legacy RLlib training stack. [Dependency declaration](https://github.com/proroklab/popgym/blob/410d5aa626dae8024f498354d8781a0d1870c399/pyproject.toml), [license](https://github.com/proroklab/popgym/blob/410d5aa626dae8024f498354d8781a0d1870c399/LICENSE.md).

## Direct learned-memory pilot, not another qualification gate

Use learned position keys of dimension 32 and values of dimension 16, with a 32-by-16 matrix. After computing the *pre-write* residual `e = v - S_pred.T @ k`, add positive uncertainty `q_local = c*k²`, where `c = kappa*mean(e²)`, before computing the diagonal gain. The hypothesis is that selective reopening preserves other useful associations better than diffuse reopening. Keep all other mean/covariance rules, initialization, modules and numerical bounds identical.

**This is not an exact Kalman posterior:** the current measurement now chooses its own gain. Positive increments and positive observation variance prevent a negative denominator; finite guards remain necessary. The final prospective design keeps the innovation statistic fully differentiable in both variants, including its dependence on the pre-write memory. This supersedes the initial stop-gradient suggestion. It is a learned residual-driven recurrence, not calibrated confidence.

**Use the pre-outcome gain-matched diffuse control**, replacing the initially discussed trace-matched control: `q_diffuse = lambda*ones(32)`, with `lambda = c*sum(k⁴)/sum(k²)`. From the same prior, both add the same amount to `k.T @ P @ k`; with the same observation variance they give the same `k.T @ gain`. This matches immediate correction along the observed key, not the complete gain vector or total covariance trace. Subsequent covariance histories can diverge, as intended. Coordinate-wise clipping can break the equality and must not be hidden. Tests should cover uniform-magnitude keys, where updates coincide, and concentrated keys, where immediate key correction matches but off-key effects differ. Report actual gain projections, key concentration, and total added trace. The local rule is coordinate-dependent, not a rotation-invariant Bayesian update.

Propose **six arms, three paired fits each**: local innovation; gain-matched diffuse innovation; ordinary diagonal KDN; DeltaNet; gated DeltaNet; GRU512. Share initial tensors wherever schemas agree, especially the two intervention arms. The GRU matches the matrix's 512 floating mean-state values, not its parameters, extra covariance, or arithmetic. Card identities are stable and clean: this tests recovery from representational interference, not hidden physical drift. A candidate that continually reopens uncertainty can erase useful evidence; that negative outcome must remain visible.

The final proposed budget is **128 training episodes, 16 epochs, batch 16, 128 updates per fit, 2,304 updates total**. Collection uses a 50:50 mixture at each decision between a public-memory matching controller and uniformly chosen publicly eligible actions. No teacher sees the hidden deck. Use Adam `0.003` and categorical cross-entropy on all previously observed, currently hidden cards before the selected reveal is written. Average queried cards within each boundary, nonempty boundaries within each episode, and eligible episodes equally. No unrevealed rank is a target. Keep complete-episode gradients and valid-prefix padding. Slow weights stay fixed at deployment. **32 separate development decks** supply final-checkpoint prediction diagnostics only, with no early stopping or selection. This is proposed scope, not a frozen recipe; no numerical seeds were assigned by this review.

**Include native deployment in this same pilot.** After all 18 fits finish, evaluate final checkpoints on the same **64 fresh decks**, with one fixed public decision rule across learned arms. With one card open, select the eligible partner with highest predicted probability of its rank. With neither open, select the pair maximizing predicted match probability, using a fixed public position order for ties. Eligibility/phase metadata is shared and counted. This is a learned belief plus supplied decision rule, not end-to-end RL or a POPGym leaderboard reproduction. Candidate reads are side-effect-free; only the actual returned event updates memory.

Use exactly two symbolic references: a full explicit public card table and an exact last-32-reveal table. Both use public evidence only. Their exact matching/exploration rule must be frozen alongside the learned decision rule; no private deck lookup is permitted. The explicit table can be smaller and better than the floating matrix; do not hide it or claim compression from Python object sizes.

Report all paired fits and decks: native return, completed pairs, success, actions, pre-reveal cross-entropy/Brier error, and repeat-query error stratified by elapsed reveals. Prespecify local-versus-gain-matched-diffuse and local-versus-unmodified-KDN comparisons; retain all conventional controls and seeds. If the diffuse control performs equally, locality is not needed. If prediction improves without native return, decision utility is unestablished. A later architecture claim needs a practically useful paired return improvement over the strongest conventional learned control, not just a recall score. A second task is warranted only after that direct result, with no reopening of the failed robotics or Mystery Path recipes.

Before execution, finish ordinary correctness tests, measured CPU sizing, and a single immutable run recipe. Record all collection, forward/backward/update, query/write, padding, storage, and full deployment costs. Count KDN's extra covariance state, GRU state, raw-history buffers, public metadata, scratch space, and exact-table payload separately. No HOLA cache is added in this pilot: it is relevant prior art and a necessary future comparator if an exact-cache extension is proposed, not another untested component to stack now.
